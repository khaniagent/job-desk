# Job agent setup (10 minutes, free)
1. Make a free GitHub account, then create a new PUBLIC repository named `job-desk`.
2. Upload every file in this folder (keep the `.github/workflows` folder and `docs`).
3. Repo Settings > Pages > Source: "Deploy from a branch", Branch: main, Folder: /docs. Save.
4. Repo Actions tab > "refresh-jobs" > Run workflow (once). After that it runs every 3 hours by itself.
5. Your page is at https://YOUR-USERNAME.github.io/job-desk/ . Bookmark it on your phone.
Edit profile.json to change your skills or keywords. Keep claims truthful: only list skills you really have in `proven_skills`.
